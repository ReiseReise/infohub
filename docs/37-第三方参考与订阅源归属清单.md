# 第三方参考与订阅源归属清单

这份文档记录信息中枢 V3 从外部项目吸收了什么、没有复制什么，以及候选订阅源的人工选择边界。

## 唯一维护入口

| 文件 | 作用 | 是否运行态 |
|---|---|---|
| `source-registry/reference-source-catalog.json` | 累计保留外部项目公开可见的全部候选源 | 否，全部默认关闭 |
| `source-registry/raw-sources.json` | Reise 确认长期维护的原始来源真源 | 否，用于重建与审计 |
| 数据库 `sources` | 当前已导入、观察或正式运行的来源 | 是 |

候选目录是累计档案，不是当天快照。外部项目暂时不再展示的来源会标记为 `historical`，不会因刷新被删除。

## 项目归属与吸收边界

### QMReader

- 上游：[joeseesun/qmreader](https://github.com/joeseesun/qmreader)
- 许可证：MIT。
- 本次核对提交：`95efab925273924963d2fdb474a67890261402e3`。
- 使用的公开材料：`lib/sources.js` 中的公开来源配置和 `/api/sources` 的公开状态。
- 吸收的产品机制：来源列表、阅读队列、正文和阅读资产分层、先抓取后 AI 的解耦，以及来源刷新中的逾期比例、来源优先级、饥饿补偿和抓取成本因子。
- 本地实现：`services/hub-engine/src/lib/source-scheduling-policy.ts` 独立实现调度因子模型，`services/hub-engine/src/scheduler/pipeline.ts` 将其接入到期来源队列；实现注释保留上游项目、许可证和提交指针。
- 代码边界：没有打包或复制 QMReader 运行时代码、页面组件和视觉资产；来源配置由信息中枢自有刷新脚本解析，调度策略按已核对的公开机制独立改写，并保留来源 URL、许可证和提交字段。

### Follow Builders

- 上游：[zarazhangrui/follow-builders](https://github.com/zarazhangrui/follow-builders)
- 许可证：仓库 README 声明 MIT；未复制代码。若后续需复制代码片段，必须再核对当时提交与完整许可证。
- 使用的公开材料：`config/default-sources.json` 中的播客、博客和 X 账号线索；2026-10-07 增加读取 `feed-x.json` 的固定五账号聚合候选。
- 吸收的产品机制：跟踪 builders 而非泛热点、长访谈候选库、统一摘要工作流。
- 代码边界：自有适配器仅解析公开配置和帖文 JSON，未复制其 agent、采集脚本、投递或提示词代码；原帖归属作者，保留原文 URL 和 Follow Builders 采集归因。当前不复用播客聚合转写，官方博客及既有播客继续使用其原始来源。

### AI HOT

- 上游：[AI HOT](https://aihot.virxact.com/)
- 许可证：未验证到可用于复制站点代码或视觉资产的公开许可证。
- 使用的公开材料：公开 feed、公开条目 API 中的来源标签、canonical 和归因信息。
- 吸收的产品机制：外部热点雷达、本地漏报对照、外部线索与本地证据分离。
- 边界：不复制页面代码、布局、图片或品牌资产；所有条目保留 AI HOT 归因和原始 canonical，无可验证原文时不进入日报核心结论。

### Dibao

- 上游：[Pls-1q43/Dibao](https://github.com/Pls-1q43/Dibao)
- 许可证：BUSL-1.1，不是 OSI 意义上的开源许可证；各发布版的 Change Date 以上游 release 为准。
- 当前用法：作为独立 Docker 侧车和同源对照阅读器，保留 Dibao 品牌与许可证入口。
- 边界：不白标、不合并 SQLite/Postgres、不将 Dibao 代码复制进主仓作为竞争性托管能力。

## Reise 的选择流程

1. 在 Sources 页打开“候选源”，按项目、渠道、推荐状态或关键词筛选。
2. 先点“预览”，核对标题、原文链接和内容类型。
3. 需要观察的来源才开始 shadow；shadow 不进入普通 Feed、日报或未读数。
4. 连续 7 天达到抓取、相关性、原文链接和噪音门禁后，再由 Reise 手工正式启用。
5. 确认长期保留的来源才追加到 `raw-sources.json`；系统导出文件不得反向覆盖原始注册表。

## 隐私和对外边界

- 邮箱、私密网页、人工反馈、阅读记录和 Article Agent 资产默认私密。
- 不自动发布资产 RSS，不将私密资产上传到外部参考站。
- 后续如果复用第三方代码，必须在同一次修改中补充：上游 commit、源文件路径、本地文件路径、许可证、修改说明和必要的 NOTICE。
