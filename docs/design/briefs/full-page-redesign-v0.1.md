# 信息中枢 v3 全页面 Figma 复刻与重设计 Brief

> 归档说明：v0.1 只保留 Baseline 与早期方向记录。当前设计真源是 Figma `01 最新设计｜桌面逐页重设计 v0.3`，本轮不使用移动端设计入口。

## 目标

把信息中枢 v3 的现有页面先复制到 Figma，形成可对照的事实基线，再基于现有功能做一版信息加工控制台方向的重设计。

## 用户与场景

使用者是 Reise 或小团队的信息处理者，核心任务不是“浏览信息”，而是把多渠道输入加工成可信、可解释、可复盘的知识和日报。

典型链路：

1. 看今天有哪些新内容和异常。
2. 判断哪些内容值得阅读、补处理或入报。
3. 追溯来源、正文、摘要、评分和日报候选的证据链。
4. 修复抓取、过滤、模型、配额和质量问题。
5. 在桌面端完成判断、阅读、修复和交付闭环。

## 设计方向

关键词：

- 信息加工控制台
- 克制高密度
- 可信证据链
- 编辑台 + 运维台
- 可解释 AI 工作流

不做：

- 不做营销式首页。
- 不做纯卡片堆叠。
- 不用大面积装饰渐变。
- 不把所有后台配置暴露在首屏。
- 不新增大量页面替代现有功能梳理。

## 页面覆盖

本轮覆盖 `App.tsx` 全路由和关键状态：

- 21 个桌面路由。
- 1 个真实 Feed 详情样本。

## 成功标准

- Figma 中能看到当前页面 Baseline 和 Redesign 的并排设计证据。
- 后续开发能根据 `design-code-map.md` 找到设计节点对应的前端路由和组件。
- Redesign 能明确提升：信息层级、状态表达、诊断解释、桌面阅读和任务回路。
