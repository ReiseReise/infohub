# 信息中枢 v3 阅读优先全页面说明 v0.5

> 归档说明：v0.5 方向错误，过度复刻参考阅读器图片，导致侧边栏和现有产品心智脱节。当前设计真源是 Figma `01 最新设计｜现有融合精修 v0.6`，详见 `page-by-page-redesign-v0.6.md`。

## 为什么补 v0.5

v0.4 保住了信息密度，但页面比例仍偏“控制台卡片”，文章列表和正文阅读不够突出。v0.5 改为参考高密度阅读器：左侧导航和分类弱化，中间保留文章流，右侧把正文、报告正文或主表格作为最大视觉区域；AI 总结、诊断、动作、证据和日志退到弱化浮层、右侧 rail、底部折叠或滚动切换里。

## 设计真源

- Figma 页面：`01 最新设计｜阅读优先全页面 v0.5`
- Figma 页面 URL：`https://www.figma.com/design/nFZbnEWt6FLIHTMSNvcPCj?node-id=52-2`
- 入口说明：`https://www.figma.com/design/nFZbnEWt6FLIHTMSNvcPCj?node-id=52-3`
- 本轮范围：桌面端全路由页面稿；移动端不恢复。

## 比例原则

- 阅读类页面：左侧导航/分类约 15%，中间文章列表约 22%，右侧正文/主阅读区约 63%。
- 治理类页面：左侧导航约 15%，主表格/主队列约 58%，右侧对象上下文约 23%，其余为间距与滚动条。
- 次级信息默认弱化：AI 总结、进度、诊断、日志、原始配置不再抢主视觉。
- 大信息量处理：列表与正文都显式保留滚动条；页面用 Tab、chips、底部折叠日志和右侧 rail 承接切换。

## 开发使用

开发时以 v0.5 为当前视觉与结构真源。v0.4 仅保留“高密度控噪”的局部参考，不再作为当前入口。

建议顺序：

1. 先改 `/feed` 和 `/feed/:id`，验证三栏比例、正文主舞台、双滚动和弱化 AI 辅助层。
2. 再改 `/sources`、`/monitor`、`/settings`，验证主表格 + 右侧对象上下文。
3. 再改日报、报告和操作队列类页面，复用主队列 + 右侧 rail + 底部折叠日志。
