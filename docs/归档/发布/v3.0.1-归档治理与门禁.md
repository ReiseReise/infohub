- 日期：2026-03-02

1. 建立 `docs/archives` 双层归档体系
2. 新增质量门禁与归档治理规范
3. 新增运维与用户/管理员手册
4. 新增门禁自动化脚本和 Makefile 入口

- 无 Breaking API 改动

## 升级步骤

1. 拉取代码并构建前后端
2. 执行 `make gate`
3. 核对 `qa/reports/index.md`

1. 回退到上一个稳定版本
2. 重新构建并运行 smoke test
3. 按 `docs/operations/rollback.md` 完成验证
