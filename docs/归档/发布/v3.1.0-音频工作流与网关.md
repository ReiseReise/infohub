# v3.1.0 发布归档 — 音频工坊与网关接入

## 1. 版本概述

- 版本：v3.1.0
- 日期：2026-03-03
- 范围：音频服务恢复、前端音频工坊、网关与代理重写、文档与回归基线更新

## 2. 主要更新

- 新增：
  - 音频工坊页面 `/audio`（上传、链接抓取、任务状态、详情渲染）
  - 音频 API 客户端与上传进度能力
  - `docs/modules/05-audio-workflow.md`
- 修复：
  - `/api/audio/*` 在 Nginx 与 Vite 的路径重写
  - 外部 JWT 首次访问 audio-service 的用户映射问题
- 优化：
  - 全量门禁回归结果归档到 `qa/reports/20260303_122907-full.md`
  - Gap 文档同步最新状态

## 3. 兼容性与影响

- Breaking Changes：无
- 配置变更：新增音频服务环境变量（见 `.env.example`）
- 数据变更：无新增 schema；audio-service 使用独立任务表模型

## 4. 升级与回滚

### 升级步骤

1. 更新 `.env`（补齐音频相关变量）。
2. 执行构建与门禁：`make gate`。
3. 重启编排：`docker compose up -d --build audio-service audio-worker hub-engine`。

### 回滚步骤

1. 回退到上一个稳定版本文档/代码。
2. 停止新增音频服务容器并恢复旧反代配置。
3. 执行 `make gate` 校验回滚后状态。

## 5. 已知问题

- 音频任务与 Feed 条目联动回写尚未完成。
- Nginx 服务仍未纳入默认 compose 启动清单（需下一版本收口）。
