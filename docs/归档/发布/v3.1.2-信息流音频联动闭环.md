# v3.1.2 发布归档 — Feed 音频联动闭环

## 1. 版本概述

- 版本：v3.1.2
- 日期：2026-03-03
- 范围：Feed 与音频工作流联动闭环、回调回写与失败可观测性增强

## 2. 主要更新

- 新增：
  - `POST /api/items/:id/audio-transcribe`（Feed 单条触发播客转写）
  - `POST /api/hooks/audio-callback`（音频任务结果回写）
  - 前端 Feed 详情的“播客转写/查看音频任务”入口
- 修复：
  - 音频任务失败时 Feed 无法及时反映失败状态的问题（新增失败回调）
  - `article_id` 仅支持整数导致 Feed UUID 无法联动的问题
- 优化：
  - 音频状态可视化（queued/processing/done/failed）
  - AudioStudio 支持 `taskId` 深链接直达任务

## 3. 兼容性与影响

- Breaking Changes：无
- 配置变更：新增可选环境变量
  - `AUDIO_SERVICE_URL`
  - `HUB_ENGINE_INTERNAL_URL`
  - `AUDIO_WEBHOOK_SECRET`
- 数据变更：无 schema 变更（使用既有字段）

## 4. 升级与回滚

### 升级步骤

1. 同步 `.env` 并按需配置上述新增环境变量。
2. 执行门禁：`make gate`
3. 重启服务：`docker compose up -d --build hub-engine audio-service audio-worker web`

### 回滚步骤

1. 回退到 v3.1.1 版本。
2. 重启相关服务并执行 `make gate` 校验。
