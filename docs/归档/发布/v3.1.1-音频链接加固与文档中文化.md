# v3.1.1 发布归档 — 音频链接抓取增强与文档中文化

## 1. 版本概述

- 版本：v3.1.1
- 日期：2026-03-03
- 范围：音频链接抓取鲁棒性增强、失败分类标准化、功能地图补全、文档主路径中文化

## 2. 主要更新

- 新增：
  - 音频任务返回来源元信息与失败分类字段（`source_kind/download_strategy/failure_code/failure_detail`）
  - 平台功能地图（含信源覆盖矩阵）`docs/design/16-平台功能地图_实现状态总览.md`
  - 迭代归档 `docs/archives/iterations/2026-03-03-音频链接抓取增强与文档中文化.md`
- 修复：
  - 播客页面链接抓取不稳定问题（新增 HTML 抽取与小宇宙兜底）
  - 失败任务缺少可定位信息问题（统一 failure code）
- 优化：
  - 设计文档主引用切换到中文文件名，英文文件保留跳转兼容
  - 文档门禁脚本新增中文主文档检查项

- 数据变更：无 schema 变更

## 4. 升级与回滚

### 升级步骤

1. 执行语法检查：`PYTHONPYCACHEPREFIX=/tmp/pycache python3 -m compileall services/audio/app`
2. 执行门禁：`make gate`
3. 重启服务：`docker compose up -d --build audio-service audio-worker hub-engine web`

### 回滚步骤

1. 回退至 v3.1.0 代码与文档。
2. 重启服务并执行 `make gate` 验证。
