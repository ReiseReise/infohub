# 2026-03-03 音频工坊接入迭代归档

## 1. 迭代目标

- 目标：把 v3 中断开的音频链路接回可用状态，补齐前端入口与网关路由。
- 预期结果：用户登录后可直接进入音频工坊，完成“上传/链接抓取 -> 任务处理 -> 查看转写/总结”。

## 2. 变更摘要

- 功能：
  - 迁入 `services/audio` 完整服务代码（含任务、提示词、模型配置、URL 抓取）。
  - `docker-compose.yml` 启用 `audio-service` 与 `audio-worker`。
  - `nginx`/`vite` 增加 `/api/audio/*` 重写到 audio-service `/api/*`。
  - 新增前端页面 `apps/web/src/pages/AudioStudio.tsx`，并挂载路由 `/audio`。
  - `apps/web/src/lib/api.ts` 新增音频任务 API（上传进度、URL 创建、重跑、模板模型读取）。
  - 兼容 hub-engine 登录态：`services/audio/app/api/deps.py` 支持外部 JWT 首次访问自动映射用户。
- 文档：
