# 2026-03-03 音频链接抓取增强与文档中文化

## 1. 迭代目标

- 目标 1：让音频工坊支持“链接即抓取下载并撰写”，并具备可排障的失败分类。
- 目标 2：将设计文档主路径统一为中文命名，补齐“平台功能地图”并可直接查看已做/未做能力。
- 目标 3：执行门禁回归，确认本轮改动可交付。

## 2. 变更摘要

### 2.1 音频链路增强

- 下载服务重构：`services/audio/app/services/podcast_service.py`
  - 支持三类输入识别：`youtube/direct_audio/podcast_page`
  - 新增多策略兜底：`yt_dlp`、直连下载、页面抽取、小宇宙专用抽取
  - 新增标准失败码：`DOWNLOAD_TIMEOUT/URL_UNSUPPORTED/DOWNLOAD_FORBIDDEN/MEDIA_NOT_FOUND/DOWNLOAD_FAILED`
- 任务接口增强：`services/audio/app/api/tasks.py`、`services/audio/app/api/tasks_from_url.py`
  - 透传来源元信息（来源类型、抓取策略、原始链接）
  - 返回失败码与失败详情，便于前端定位问题
- 流水线元信息透传：`services/audio/app/tasks/audio_pipeline.py`
  - `_source_meta` 和 `_callback` 贯穿 Step1-5，避免中间状态覆盖
- 前端展示增强：`apps/web/src/pages/AudioStudio.tsx`
  - 任务详情展示来源类型、抓取策略、失败码、失败详情

### 2.2 文档中文化与能力地图

- `docs/design/` 主文档已统一中文命名，并保留英文文件名跳转页兼容历史链接。
- 新增能力总览：`docs/design/16-平台功能地图_实现状态总览.md`
  - 增补“信源覆盖矩阵”（RSS/播客/YouTube/个人站/API/X/公众号/Newsletter）
  - 明确每项能力状态（已完成/部分完成/未完成）
- 同步模块文档：`docs/modules/05-audio-workflow.md`（抓取策略与失败码）
- 强化文档门禁：`scripts/docs/check-docs.sh` 增加中文主文档检查项

## 4. 遗留问题

1. Feed 条目与音频任务仍为松耦合，尚未实现“一键转写并回写状态”。
2. X、公众号等非 RSS 信源尚未工程化接入。
3. Nginx 统一入口未纳入默认 compose 启动链路。

## 5. 下一迭代建议

1. 完成 Feed 与 Audio 的条目级联动闭环（触发、状态、详情跳转）。
2. 增加小宇宙/YouTube/直链抓取的端到端自动化用例。
3. 推进非 RSS 信源（X、公众号）接入方案与最小可用实现。
