# Phase 2 归档：AI 处理与输出层

## 1. 阶段目标与边界

- 目标：完成 AI 评分/摘要/翻译处理器与日报/导出通道。
- In Scope：processors、outputs、insights/export API、对应 QA。
- Out of Scope：向量检索与复杂前端交互。

## 2. 输入上下文

- 依赖：Phase1 API 与采集数据可用。
- 条件：AI 配置可选，未配置时处理器降级跳过。

## 3. 关键决策

| 决策 | 原因 | 结论 |
|---|---|---|
| 处理层与输出层分离 | 便于独立扩展和调试 | `processors/` 与 `outputs/` 独立目录 |
| 导出支持 Obsidian 与知识库双通道 | 满足知识沉淀场景 | 输出目录结构标准化 |

## 4. 实施清单

| 项目 | 状态 | 说明 |
|---|---|---|
| AI 评分/摘要/翻译处理器 | ✅ | `ai-scorer.ts` / `ai-summarizer.ts` |
| 日报与导出 API | ✅ | `routes/insights.ts` / `routes/export.ts` |
| 定时任务接入 | ✅ | daily report + priority update |
| Phase2 QA | ✅ | 20 PASS / 0 FAIL / 0 SKIP |

## 5. 变更清单

- 代码：`services/hub-engine/src/processors/*`、`services/hub-engine/src/outputs/*`
- 路由：`services/hub-engine/src/routes/{insights,export}.ts`
- 文档：`docs/phase2-ai-outputs.md`

## 6. 测试证据

- 命令：`bash qa/phase2/test_ai_outputs.sh`
- 结果：20 PASS / 0 FAIL / 0 SKIP

## 7. 风险与技术债

- AI 质量与成本依赖模型配置和提示词。
- 日报内容质量受上游抓取质量影响。

## 8. 回滚方案

1. 禁用 AI 开关：`AI_PROCESSING_ENABLED=false`
2. 回退 processors/outputs 路径代码
3. 验证 insights/export 接口恢复
