# Phase 4 归档：扩展采集器 + Webhook

## 1. 阶段目标与边界

- 目标：实现多采集器扩展与外部数据注入能力。
- In Scope：changedetection/youtube/custom 采集器，hooks API。
- Out of Scope：深度内容清洗和多模态高级处理。

## 2. 输入上下文

- 依赖：Phase1 的采集 pipeline 已稳定。
- 前置：RSSHub 和 changedetection 服务可用。

## 3. 关键决策

| 决策 | 原因 | 结论 |
|---|---|---|
| 采集器标准接口统一 | 降低新增采集器成本 | 继承 base collector 接口 |
| Webhook 注入走独立路由 | 便于外部系统接入 | 新增 `/api/hooks/*` |
