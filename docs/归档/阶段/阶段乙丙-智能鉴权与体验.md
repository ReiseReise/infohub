# Stage B+C 归档：AI 处理 + 前端增强 + 认证隔离

## 1. 阶段目标与边界

- 目标：打通 AI 配置与规则管理，同时完成前后端认证隔离与关键 UX 闭环。
- In Scope：JWT、登录注册、受保护路由、Feed 详情预览、Sources OPML UI、QA 认证化。
- Out of Scope：音频工坊完整迁移与多源融合平台化。

## 2. 输入上下文

- 依赖：Phase1-5 基础能力可用。
- 前置：数据库已有 `auth.users` 和 `quota` 结构。

## 3. 关键决策

| 决策 | 原因 | 结论 |
|---|---|---|
| 全业务路由强制 `requireAuth` | 防止多用户串数据 | 全路由改为按 `user_id` 隔离 |
| 前端新增 AuthProvider + Guard | 统一登录态与路由控制 | `App.tsx` 受保护路由接入 |
| QA 脚本统一 `qa/helpers/auth.sh` | 保证回归在真实鉴权上下文 | phase2/4/5/stage-a/stage-bc 全接入 |
