# Phase 0 归档：基础设施搭建

## 1. 阶段目标与边界

- 目标：完成基础组件启动、数据库初始化、健康检查基线。
- In Scope：Docker Compose、DDL、基础服务连通性、Phase0 QA。
- Out of Scope：业务功能与前端交互。

## 2. 输入上下文

- 关键依赖：PostgreSQL、Redis、RSSHub、changedetection、ntfy。
- 前置条件：`.env` 配置可用，Docker 可运行。

## 3. 关键决策

| 决策 | 原因 | 结论 |
|---|---|---|
| 使用 `pgvector` 作为默认数据库镜像 | 后续需要向量检索能力 | 采用 `pgvector/pgvector:pg16` |
| 基础组件全部容器化 | 降低环境漂移 | 使用 `docker compose` 统一编排 |

## 4. 实施清单

| 项目 | 状态 | 说明 |
|---|---|---|
| Compose 基础服务编排 | ✅ | `docker-compose.yml` 完成 |
| 数据库初始化脚本 | ✅ | `scripts/init-db.sql` |
| 基础设施 QA 脚本 | ✅ | `qa/phase0/test_infrastructure.sh` |

## 5. 变更清单

- 配置与脚本：`docker-compose.yml`、`scripts/init-db.sql`
- 文档：`docs/phase0-infrastructure.md`

## 6. 测试证据

- 命令：`bash qa/phase0/test_infrastructure.sh`
- 结果：30 PASS / 0 FAIL / 1 SKIP（RSSHub 外网路由偶发 503）

## 7. 风险与技术债

- RSSHub 外网依赖存在不稳定性。
- 组件健康检查通过不代表业务链路可用。

## 8. 回滚方案

1. `docker compose down`
2. 恢复上一版本 compose 与 init SQL
3. `docker compose up -d` 后重新执行 phase0 QA
