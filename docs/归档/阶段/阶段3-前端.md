# Phase 3 归档：统一前端

## 1. 阶段目标与边界

- 目标：提供可用的 Web 工作台，覆盖 Feed/Sources/Insights/Export/Settings。
- In Scope：React 前端、路由、基础交互、构建发布产物。
- Out of Scope：高级交互动画与移动端深度适配。

## 2. 输入上下文

- 依赖：Phase1/2 API 已可调用。
- 前置：Vite 构建链路正常。

## 3. 关键决策

| 决策 | 原因 | 结论 |
|---|---|---|
| 使用单体前端 + 侧边栏导航 | 降低切换成本 | 页面集中在 `apps/web/src/pages` |
| API 统一封装到 `lib/api.ts` | 降低请求重复与错误 | 所有页面复用统一请求层 |
