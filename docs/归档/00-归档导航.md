# 归档导航

`docs/归档/` 只存放历史过程材料，不承担当前状态解释权。

## 归档目录

| 目录 | 内容 |
|---|---|
| `阶段/` | 早期 Phase / Stage 阶段文档 |
| `迭代/` | 单轮实施记录、收口记录、阶段 QA 样本 |
| `发布/` | 发布摘要与里程碑版本说明 |
| `评审/` | 代码审查、项目审查、验收审查材料 |
| `模板/` | 归档模板、发布模板、QA 模板 |

## 使用原则

1. 查当前状态，不要从这里开始，应回到 `../02-当前状态与功能地图.md`
2. 查历史过程、阶段性判断、评审证据，再进入这里
3. 归档允许保留更多历史命名痕迹，但目录入口已经统一中文化
4. 最新一轮关于数据新鲜度与 AI 治理的 review 见 `评审/2026-03-19-项目评审_数据新鲜度与AI治理.md`
