# 信息中枢 V3 日报主链路收口验收记录

日期：2026-06-06
阶段：可信可用收口计划模块 4
范围：Insights 日报预览、日报生成、候选池噪声收紧、最终 Markdown 可读性、Feed 详情快照一致性。

## 结论

本轮用 acceptance admin 真实数据反复跑“预览候选池 -> 生成日报 -> 读取最新日报快照 -> Feed 详情诊断”闭环，修复三类直接影响信任感的问题：

1. 泛金融监管讲话混入 TOP：`证监会主席吴清：坚决遏制概念炒作...` 含有 AI/科技赋能字样，但本质是金融行业治理讲话，不能作为 AI/科技日报主内容。
2. 债券/融资市场新闻混入 TOP：`境外发行人前5个月发行规模超去年全年...点心债...` 被宽 scope 的 `融资/金融` 关键词吸入，实际是泛金融市场噪声。
3. 最终 Markdown 可读性不稳：`今日结论` 曾出现孤立尾巴 `AI` 或缺句号，`AI 产业与产品信号` 曾保留模型误判内容。

修复后最新真实结果：

- 预览和生成 TOP 完全一致：`topOverlap=5/5`。
- `businessNoiseInTop=[]`。
- `excludedByReason.business_noise=7`。
- `fallback_scored=9` 只进入诊断，不进入最终日报。
- Markdown 长度 `3780`，关键章节齐全，`hasOrdinalRefs=false`。
- Feed 详情中证监会讲话、点心债新闻都显示 `未入报：泛商业噪声`，依据为 `同日最新日报快照`。

## 修复 1：泛金融监管讲话不入报

新增回归测试：

- `keeps generic securities regulator speeches out of scored daily candidates`

真实漏网样本：

- ID：`9b32ee18-da32-4719-9ced-8dd39b4d0731`
- 标题：`证监会主席吴清：坚决遏制概念炒作、复杂嵌套、过度投机、通道空转等伪创新、乱创新`
- 修复后：`excludedReason=business_noise`

实现：

- 在 `classifyDailyReportReviewBucket` 中增加金融治理类噪声判断。
- 覆盖 `证监会/基金业协会/证券投资基金/基金行业/投资投研/内控/风险防控/概念炒作/通道空转/伪创新/乱创新` 等信号。
- 但保留真实 AI 模型监管内容，例如 `欧盟发布 AI 模型监管实施细则` 仍可进入 AI/科技复核。

## 修复 2：债券/融资市场新闻不入报

新增回归测试：

- `keeps bond market financing news out of scored daily candidates`

真实漏网样本：

- ID：`b3317ead-3144-4625-ba7f-faf79e4db558`
- 标题：`境外发行人前5个月发行规模超去年全年 外资积极入场助点心债热度高企`
- 修复后：`excludedReason=business_noise`

实现：

- 扩展泛商业/金融噪声词表：`点心债/债券/境外发行人/发行规模/融资成本/外资入场/外资机构/人民币国际化/人民币资产/金融市场开放`。
- 即使用户 workflow scope 包含 `融资/商业/金融`，这类内容也不会进入日报 TOP。

## 修复 3：最终 Markdown 确定性后处理

新增回归测试：

- `final ai markdown removes dangling truncated conclusion fragments`
- `final ai markdown completes conclusion punctuation and rewrites industry signals deterministically`

实现：

- `今日结论` 后处理：
  - 移除章节尾部孤立英文碎片，例如 `。AI`。
  - 缺少终止标点时补 `。`。
- `AI 产业与产品信号` 后处理：
  - 不再保留模型自由输出。
  - 按 TOP 条目和 AIHOT 分类确定性生成标题链接、来源、标签和摘要。
