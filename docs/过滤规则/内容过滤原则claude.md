# 内容过滤原则

> 核心理念：不需要看得多，需要每一条都值得看。
> 不做信息的猎人，做信息河流中的泡澡者。

---

## 一、信息质量判断（五条红线）

### 1. 信息密度检验

**判断问题：** 去掉举例和铺垫后，干货还剩多少？

- 通过：核心观点浓缩、提炼过，信息密度高
- 淘汰：万字长文但核心观点两三句话就能说清，大量注水和重复

### 2. 独立洞察检验

**判断问题：** 有没有哪句话让我停下来想了一下？

- 通过：有作者自己的判断、点评、非共识观点，能提供新视角
- 淘汰：只是将已知信息重新排列组合，没有原创思考

### 3. 实操性检验

**判断问题：** 看完之后我能用上什么？

- 通过：涉及真实决策过程、踩过的坑、具体操作方法
- 淘汰：全是宏观趋势和概念堆砌，看完只是"知道了"但无法落地

### 4. 动机纯净度检验

**判断问题：** 作者写这个的动机是什么？有没有利益相关？

- 通过：客观呈现，不带隐性引流、卖课、推产品、造势目的
- 淘汰：以"客观分析"为外衣，最终导向让你买东西或关注某人

### 5. 半对半错检验（最重要）

**判断问题：** 在我熟悉的部分里，作者说的准不准？有没有明显遗漏？

- 通过：在你熟悉的领域内表述准确，没有关键遗漏
- 淘汰：你熟悉的部分有硬伤或明显遗漏 → 你不熟悉的部分大概率也有问题
- 警示：半对半错是最危险的信息类型，全错反而一眼能辨别

## 二、信息源质量判断（四个维度）

### 6. 周期经验

**判断问题：** 这个作者在这个领域做了多久？有没有实际从业经历？

- 优选：经历过至少一个完整行业周期，知道什么大概率是错的
- 警惕：没有实操经验，仅靠二手信息拼凑

### 7. 更新稳定性

**判断问题：** 这个信息源是持续更新的，还是三天打鱼两天晒网？

- 优选：持续稳定输出半年以上，稳定性远比及时性重要
- 警惕：偶尔爆发一篇，缺乏持续性

### 8. 受众匹配度

**判断问题：** 这个内容的目标读者是谁？是不是我这个层级？

- 优选：与自身水平匹配或略高一档
- 警惕：面向大众科普（密度不够）或过于专深（消化不了）

### 9. 认知差异度

**判断问题：** 这个信息源最近有没有让我感到意外或不舒服的内容？

- 优选：偶尔让你觉得"不太同意"或"没想过这个角度"
- 警惕：每次看都觉得"没错，我也这么想" → 只是在强化已有认知，边际价值递减

## 三、快速过滤决策流程

拿到任何一条内容，按顺序执行以下三步：

```
第一步：有没有隐性商业目的？
  ├─ 有 → 降低优先级或直接跳过
  └─ 无 → 进入第二步

第二步：在我熟悉的部分，有没有明显错误或遗漏？
  ├─ 有 → 直接丢弃（半对半错最危险）
  └─ 无 → 进入第三步

第三步：去掉铺垫和举例，核心干货能否三句话说清？
         这三句话里有没有让我停下来想一想的？
  ├─ 有 → 值得留下
  └─ 无 → 跳过
```

## 四、信息价值的底层认识

- 大部分信息的价值是短暂的，会迅速贬值
- 一天后只能记住 20-30%，一个月后约 2%
- 超过 80% 的价值在于"意识到自己不知道什么"，而非信息内容本身
- 真正重要的高价值信息一定会反复出现，你最多晚一两天或一两周
- 主动筛选信息存在认知幻觉：你只会选择与已有认知契合的内容
- 与其追逐信息，不如把自己泡到优质信息的河流里，感受流动变化
