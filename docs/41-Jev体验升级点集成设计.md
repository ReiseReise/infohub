# Jev 全场景旁路集成设计与使用

Jev 给信息中枢增加快速判断建议：该不该加工、材料是否够用、变化是否重要。摘要、翻译、研究、算术、日期比较和权限控制继续由原有模型或代码负责。全部建议与正式评分、处理状态分开存储。

Reise 于 2026-09-22 确认：全部候选场景纳入接入，先旁路；仅公开材料可以发送；本轮新增调用累计预算为 1 美元。旧稿“盲审前不动代码”的开工约束由本次明确指令替代，**质量验收与自动生效门槛没有取消**。当前执行与上线状态以 [36 号文件](36-信息中枢V3可信可用收口任务跟踪.md) 为准。

## 1. 从哪里进入，怎样使用

管理员打开 **设置 → AI 管理中心 → Jev 判断工作台**，或 `/jev`。Feed 条目详情、来源、网页监控、音频工坊和研究页也有对应建议入口。

1. 查看运行开关、凭据是否就绪及剩余预算；缺少条件时界面不得显示已经运行。
2. 确认资料公开性。来源确认适用于该来源的自动采集内容；私人邮件、上传、剪藏不会因来源公开而自动获准发送。单条资料可单独确认或撤销。仅有网址不构成公开性证明。
3. 将需要的场景设为“旁路”，允许新增调用。`JEV_ENABLED=true` 和原有 `AI_PROCESSING_ENABLED=true` 仍须满足。
4. 新条目走旁路队列；也可在条目详情请求指定场景建议，在工作台评估最近 30 条候选，在来源控制中评估最多 20 条已有内容。
5. 刷新结果，比较建议和原评分，记录赞同、不赞同或重要漏选。所有量表注明范围，不直接比较 Jev 的 0–2 分与原有评分。
6. “按建议排序”和“预览同事件折叠”只作用于建议列表。取消选项可恢复全部展示；Feed 主列表不被改写。
7. 点击“完整处理（原流程）”可调用既有手动处理入口。Jev 不拦截手动操作。此按钮可能触发原有生成模型费用，不属于本轮对照实验的自动任务。
8. “停止新增调用”禁止后续预算预留；已发出的请求不能撤回，其结果不会应用。关闭全部场景保留历史记录。

界面状态：**仅建议/未运行/失败回退/材料已更新/公开冻结样本实验**。实验记录不能当成当前条目的质量认证。当前版本不开放自动生效，后端也拒绝 `active` 模式；不能只改数据库枚举宣称功能已经生效。

## 2. 场景与接入位置

| 场景 | 输入与接入时机 | 判断与展示 | 当前实际动作 |
|---|---|---|---|
| Feed 初筛 | 条目入库；标题、可读正文或摘要 | 相关性、材料充分性、主题、产业/应用/资本三视角 | 保存独立建议，正式排序不变 |
| 加工分级 | 新条目的独立任务，与原加工并行 | full/brief/skip/insufficient + 信息密度 | skip 仅建议，保守映射 brief；不跳过原加工 |
| 摘要档位 | 复用加工分级结果 | detailed/one_sentence | 显示拟用档位；不会生成第二份付费摘要 |
| 可疑指令 | 清洗后的正文 | suspect 提示，不判定安全 | 评分及摘要/翻译输入明确标为外部资料；检测不控制权限 |
| 监控变化 | changedetection 条目及前一版同源快照；公开监控目的 | 本地计算新增/删除片段，再判实质性 | 提醒不抑制；缺前版或目的则未运行 |
| 动态补抓 | 本地提取未满足条件、动态兜底前 | worth/defer_fetch | 保留原 Scrapling/browser-assist 路径 |
| 新源评估 | 管理员主动选择来源的最近最多 20 条 | 单条相关性、充分性与质量，API 可汇总 | 不阻止导入、不自动订阅 |
| 转写前 | 现有自动转写资格检查通过后、任务创建前 | 语音类型、预期价值 | 仍执行原有时长、日额度与费用限制 |
| 转写后 | 音频服务在摘要前通知 Hub；只传关联条目 ID | readable/broken/insufficient | Hub 读取已保存稿件并检查公开性，不中断原摘要 |
| 剪藏去处 | 入库及手动请求，仅已确认公开材料 | news/knowledge/hold | 可确认本地整理去处标记；不会自动导出知识中枢 |
| 同事件折叠 | 本地 cluster_id 先筛，最多取 3 个候选 | 仅比较两条，不把后续进展或分析当同事件 | 只预览不物理合并；不传递推断 A=B=C，不允许双向关系隐藏全部 |
| 日报候选 | 可信研究创建选材快照时，或手动候选评估 | 三视角候选排序 | 独立比较，不改日报选材与默认引擎 |
| 兴趣匹配 | 题型、入口和合成测试具备 | 显示隐私限制 | 始终关闭；不读取或发送真实偏好 |

监控当前使用系统已有的截取快照，不声称覆盖页面完整差异；缺乏完整证据时不能开放抑制提醒。转写前与转写后为两个不同材料阶段，各自调用。公开新闻用于剪藏去处分流的实验，只验证该题型，不能替代真实剪藏旅程验收。

## 3. 工程设计与数据契约

核心代码在 `services/hub-engine/src/jev/`：`contracts.ts` 集中题库、校验、阈值和本地规则；`client.ts` 为唯一云出口；`store.ts` 管理资料、判断和费用；`service.ts` 组织一次判断；`queue.ts` 连接 BullMQ。Web 共用 `JevPanel`，音频通过内部鉴权接口发送条目引用。

- 固定 `jev-1.13.0`，问题版本 `2026-09-22.1`，HTTP 3 秒超时，无自动重试。定向 API 不复用聊天模型接口。
- 校验模型版本、答案键集合、题型、概率范围与总和、Choice 选项、Score 字典及权威 score、用量整数。非法或非有限数值回退原流程。
- 一份材料中同场景多个问题合并调用；相同材料不同场景尚各自调用，费用统计包括这部分开销。
- 原文清洗并裁剪：一般正文 6000 字符、标题 500；转写 10000；监控增删片段各 3000；这是字符上限，不冒充精确 token 计数。
- 材料充分性要求 ≥0.8；Choice/Score confidence 要求 ≥0.8。普通 Noul ≥0.8 为肯定，≤0.2 为否定，中间回原流程。同事件预览阈值 0.85。阈值是保守起点，不是已校准准确率。
- 源语言单独存储与报告；中文参与旁路实验，未获得自动生效资格。
- 独立 `jev-shadow` 队列，并发 2、attempts=1；Redis 只保存场景和对象引用，不存正文、偏好或密钥。观察入口异常不阻塞原流程。
- 请求去重包含场景、对象、材料哈希、模型和题库版本。数据库主键和事务锁共同防重复。返回及展示时检查材料版本；旧版本只能作为历史，不能覆盖新建议。

增量 SQL：`scripts/jev/001-jev.sql`，仅创建以下表，重复执行不重置预算：

| 表 | 用途 |
|---|---|
| `hub.jev_control` | 单实例停止开关与各场景模式；初始全部关闭 |
| `hub.jev_budget` | 固定本轮 ID 和 1,000,000 微美元上限，已结算与预留不能超过上限 |
| `hub.jev_decisions` | 版本、公开性依据、语言、建议、实际动作、耗时、费用、状态；不保存请求正文 |
| `hub.jev_feedback` | 追加人工反馈，不覆盖原判断 |
| `hub.jev_acceptance` | 预留分场景/语言验收记录，当前未填充通过证据 |

HTTP 位于 `/api/jev`：管理员读写 config、decisions、evaluate、batch、feedback；sources 列表、公开性声明和样本评估；单条公开性声明；capture/confirm；source-report。`internal/transcript` 只接受内部密钥和条目 ID，不接受外部任意正文或模型凭据。

## 4. 预算、隐私、停止和恢复

本轮所有真实 Jev 验证与后续旁路使用同一个生产数据库账本 `jev-20260922`。按当前官方每百万输入 token 0.042 美元估算，以 UTF-8 请求字节数加 2048 作为保守输入预留。每次先锁定预算、预留再发请求；成功按输入用量结算；失败或未知保留预留额。三次近期异常进入 10 分钟保守熔断。超出预留立即停止，不自动释放未知费用。

现有 token 长度限制和来源条数限制均不是金额账本，本方案没有把它们当作美元上限。当前按微美元向上取整，估算可能略高于精确账单；没有宣称完成实际账单核对。

公开性必须由来源或单条明确声明；私人类型不能继承普通来源声明；单条撤销优先。URL 中包含登录信息、查询参数、局域网或本地地址时拒绝发送。只用原文/节目简介/公开转写，不拼接个人偏好、阅读记录、私人备注或 user_instruction。密钥仅在现有私有运行配置中，所有 API/日志不回显。

回退优先停止新增调用并关闭场景，再恢复本轮保存的旧镜像。新增表保留作为审计，不需删除。原文、旧评分和旧研究结果没有被 Jev 改写；恢复数据库是更大范围的灾难恢复动作，不能在正常运行中为了回退 Jev 直接覆盖后来新增的业务记录。

## 5. 验收与已知限制

工程验收包括题型与异常单测、所有场景隔离 DB 流程、真实 Redis 消费、并发金额预留、恢复不重复调用、隐私阻断、过期结果、管理员鉴权、内部鉴权，以及桌面/390 像素手机页面。完整 `make gate` 及最新证据见 [Jev 验收说明](../qa/jev/IMPLEMENTATION-20260922.md)。

真实实验复用原 30 条已核验公开的冻结新闻，七种适用场景各 30 次，全部使用实际 Jev API。它不证明监控、音频或同事件质量；冻结记录带独立状态，与实时建议分开。原有 10 条盲审文件不覆盖。

自动生效仍需：各场景至少 30 个适用样本、同事件 50 对、中文独立报告；减少处理的建议逐项人工核对；重要漏选立即否决；同事件误折叠不超过原定 10% 门槛；监控另外观察两周。当前没有足够人工标签与观察证据，**没有自动过滤、节省费用或内容质量通过的结论**。
