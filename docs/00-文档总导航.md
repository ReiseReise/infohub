# 信息中枢 V3 文档总导航

这轮重构后的原则很简单：`docs/` 根目录只保留少数活跃主文档，所有历史过程材料统一进入 `docs/归档/`。

## 先看哪几份

| 文档 | 用途 |
|---|---|
| `01-顶层架构设计.md` | 看系统定位、五层架构、数据流、部署与模块边界 |
| `02-当前状态与功能地图.md` | 看当前做到哪、顶级设想对照总表、哪些能力该先做 |
| `03-路线图与优化计划.md` | 看下一步优先级、三层推进路线、Folo 借鉴边界 |
| `04-关键实现专题.md` | 看 Feed、Audio、日报、Discovery 等关键专题 |
| `05-运维与使用手册.md` | 看启动、迁移、排障、用户与管理员使用方式 |
| `06-质量门禁与测试规范.md` | 看回归标准、文档治理、归档规则 |
| `07-总览仪表板.html` | 用 HTML 快速看整体进度、流程和验收入口 |
| `08-AIHOT公开信源候选库.md` | 看从 AIHOT 公开页整理出的候选信源、分层、风险与导入前验收 |
| `14-多剪藏入口CaptureInbox接入.md` | 看 Obsidian、Zotero、Organic Notes 等剪藏入口如何统一进入信息中枢与知识中枢 |
| `归档/00-归档导航.md` | 看阶段、迭代、发布、评审等历史材料 |

## 阅读顺序

1. 新接手项目：先看 `01`、`02`
2. 想知道接下来做什么：看 `03`
3. 要理解实现细节：看 `04`
4. 要启动、迁移、排障：看 `05`
5. 要执行回归与治理：看 `06`
6. 想追历史过程：看 `归档/00-归档导航.md`

## 当前文档规则

1. 活跃文档全部放在 `docs/` 根目录。
2. 活跃文档全部使用中文命名。
3. 历史材料统一保留在 `docs/归档/`。
4. 不再保留旧目录壳的兼容跳转文件。
5. 当前状态以 `02-当前状态与功能地图.md` 为唯一解释权入口。
6. QA 基线仍以 `qa/reports/index.md` 为准，`docs/` 只负责说明与导航。
