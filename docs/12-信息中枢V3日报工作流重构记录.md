# 信息中枢 V3 日报工作流重构记录

updated: 2026-05-12
status: implemented

## 目标

本轮修复日报的核心问题不是“让日报不空”，而是让日报生成过程可解释、可配置、可验证：

- 用户能在成长仪表盘看到日报从内容入口到生成结果的完整链路。
- 英文候选必须在入报前中文化；中文化失败的条目进入诊断，不进入最终候选。
- 高分精选和最新兜底分开标识，避免低价值内容伪装成关键进展。
- Prompt 链路显式暴露为日报清洗、决策简报、研究汇总、阅读导航、最终日报五个场景。

## 后端改造

- 新增 `daily-report-workflow.ts`，独立承载日报工作流默认配置、配置归一化、候选池准备和中文化门禁。
- `user_settings.daily_report_workflow` 用于保存用户级日报工作流配置。
- 新增接口：
  - `GET /api/insights/workflow`
  - `PUT /api/insights/workflow`
  - `POST /api/insights/workflow/preview`
- `POST /api/insights/generate` 默认读取已保存的工作流配置；URL 参数仍可临时覆盖 `topN/minScore`。
- 日报候选池新增漏斗：
  - `todayNew`
  - `mainVisible`
  - `scopeMatched`
  - `scoredCandidates`
  - `latestFallbackCandidates`
  - `translationPending`
  - `translationFailed`
  - `finalCandidates`
- `TopItem` 增加展示字段：
  - `displayTitle`
  - `reportSummary`
  - `language`
  - `translationStatus`
  - `selectionReason`
  - `selectionMode`
- 日报顶部增加“生成口径”，用于说明今日新增、主流程可见、高分候选、最新兜底、翻译失败和最终入报数量。

## 前端改造

- 成长仪表盘新增“日报工作流”入口。
- 工作流面板包含五段流程：
  - 内容入口
  - 入报筛选
  - 入报前中文化
  - Prompt 链路
  - 生成与兜底
- 可编辑参数：
  - 最低精选分
  - 入报条数
  - 每信源上限
  - 是否允许最新兜底
  - 是否强制中文
  - 入报分类
  - 关键词范围
  - 信源等级
  - 五个日报 Prompt 场景启停
- 支持候选池预览，不写入日报。
- 预览展示最终候选和未入报诊断，方便判断“今天有新内容但为什么没进日报”。

## 验证结果

- `services/hub-engine`: `npm test && npm run build` 通过。
- `apps/web`: `npm run build` 通过。

## 剩余风险

- 预览接口为了避免写库，不会真的触发翻译；正式生成时才会调用翻译链路。
- 如果翻译场景未配置或模型不可用，英文条目会进入“翻译失败/未中文化”诊断，不会硬塞进日报。
- 旧日报不会批量重写，新逻辑只影响后续生成和手动重新生成的日报。
