## 修复 1：Sources 质量指标口径对齐

文件：

- `apps/web/src/features/sources/page.tsx`

修复：

- `AI率` -> `AI完成率`
- `噪声` -> `噪声率`
- `精选率` -> `日报入选率`
- 表格日报入选率从 `selectedHitRate` 改为 `source.sourceQuality?.reportSelectedRate`

原因：

Sources 是主治理面，指标名称必须让用户直接看懂来源质量，而不是在“精选反馈”和“日报入选”之间猜。

## 修复 2：P0 前端 E2E 支持真实栈复用

文件：

- `qa/p0/test_frontend_e2e_folo.sh`

修复：

- 新增 `E2E_USE_EXISTING_STACK=auto` 默认模式。
- 如果 `http://127.0.0.1:3001/health` 和 `http://127.0.0.1/login` 已可用，则复用当前 Docker 栈。
- 复用 Docker 栈时，本地测试 RSS feed 暴露给容器使用 `http://host.docker.internal:<port>/feed.xml`。
- 保留 `E2E_USE_EXISTING_STACK=0` 强制旧 dev-stack 行为。

原因：

当前本地可信验收的事实源是 Docker 栈。旧脚本硬起本机 dev 后端，可能卡在本机数据库/环境变量/沙箱条件上，导致测不到真实页面。
